# ADR 0009: `mise.toml`の書き換えはTOMLライブラリでの完全パースではなく正規表現ベースの行単位置換にする

## Status

Accepted

## Date

2026-09-11

## Context

mise-bump-actionは`mise.toml`中の1つのツールバージョンだけを書き換えてPRを出す。
TOMLライブラリ(例: `BurntSushi/toml`, `pelletier/go-toml`)でパース→値変更→
シリアライズする方式は、コメント・キーの並び順・フォーマット(タブ/スペース、
クォートスタイル)を完全に保持できる保証がなく、無関係な差分がPRに混ざるリスクがある。
Dependabotのような「該当ツールのバージョン行だけを変更したPR」という体裁(ADR 0003)
を実現するには、ファイルの他の部分を一切変更しないことが重要。

## Decision

`internal/misetoml.Bump`は、TOMLパーサーを使わず、対象キーの行を正規表現で直接特定して
その行の値部分だけを文字列置換する。行の分割・結合は`\n`ベースで行い、CRLF・末尾コメント・
タブ区切りの`=`にも対応する。

## Rules

- `mise.toml`の書き換えは`internal/misetoml.Bump`を経由し、他の書き換え手段(TOMLライブラリ
  の導入等)を追加しない。
- 対象キーが見つからない、値が単純な文字列でない(インラインテーブルや配列)場合はエラーを
  返し、無理に書き換えようとしない。

## Consequences

- コメント・フォーマット・キー順序は完全に保持される。
- 複雑なTOML構造(ネストしたインラインテーブル等)でのバージョン指定には対応しない
  (エラーを返す)。将来的にそのような構成をサポートする場合は、この決定を見直す必要がある。
